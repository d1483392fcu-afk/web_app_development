# PRD - 個人記帳簿系統

## 1. 專案概述
- **背景與動機**：現代人生活開銷零碎，若沒有記帳習慣容易變成「月光族」，或是不清楚自己的金流去向。市面上的記帳軟體有時過於龐大或帶有廣告，因此希望能打造一款簡潔、專注於核心功能的個人記帳簿系統。
- **目標用戶**：有記帳需求的一般大眾（如學生、上班族、家庭主婦等），希望掌握個人或家庭財務狀況並樂於控制每期收支的人。
- **核心價值主張**：提供直覺的記帳介面、多帳戶的資金管理，並輔以預算提醒與圖表分析，幫助用戶輕鬆掌握財務狀況並達成理財目標。

## 2. 功能需求
1. **記錄收支明細**
   - 作為 **使用者**，我希望 **能夠快速新增每筆收入或支出（包括金額、日期、分類、帳戶、備註）**，以便 **準確追蹤我的資金流向**。
2. **管理多個帳戶**
   - 作為 **使用者**，我希望 **能夠建立與管理多個帳戶（如現金、銀行帳戶、信用卡等）**，以便 **掌握各個帳戶的餘額與資金水位**。
3. **設定預算控制開銷**
   - 作為 **使用者**，我希望 **能夠針對不同分類或整體設定每月預算**，以便 **在快超支時獲得提醒，控制花費**。
4. **分類標籤管理**
   - 作為 **使用者**，我希望 **能夠自訂收支分類（如餐飲、交通、娛樂等）**，以便 **根據自己的消費習慣去歸類記帳項目**。
5. **圖表統計分析**
   - 作為 **使用者**，我希望 **能查看月度的收支圓餅圖與趨勢圖**，以便 **一眼看出本月的最大開銷在哪裡，方便後續檢討**。

## 3. 非功能需求
- **技術限制**：後端採用 Flask 框架，前端使用 Jinja2 模板渲染，資料庫採用 SQLite（以輕量化、本地端存儲為主）。
- **效能考量**：操作介面需具備高回應速度，頁面載入時間應低於 1 秒。
- **安全考量**：防範常見的 Web 攻擊（如 XSS, CSRF, SQL Injection）。若是單機個人使用，仍需考慮未來可能加入的多人帳號密碼登入與資料隔離安全機制。

## 4. MVP 範圍
- **Must Have (必須有)**
  - 記錄收支明細（新增、編輯、刪除收支項目）
  - 管理多個帳戶與即時計算總餘額
  - 設定每月總預算與顯示預算剩餘金額
  - 提供預設的收支分類
- **Should Have (應該有)**
  - 分類標籤管理（使用者自訂分類）
  - 圖表統計分析（基本的圓餅圖分析花費比例）
- **Nice to Have (錦上添花)**
  - 帳戶間的資金轉帳功能
  - 匯出收支紀錄報表（CSV 格式）
  - 獨立登入系統與多使用者支援
